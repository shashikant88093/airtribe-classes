## subarray , substring , subset, subsequence


### Definitions

- **Subarray**: A contiguous portion of an array. For example, in the array `[1, 2, 3]`, `[2, 3]` is a subarray.
- **Substring**: A contiguous sequence of characters within a string. For example, in the string `"hello"`, `"ell"` is a substring.
- **Subset**: A set formed from another set by removing some elements without changing the order of the remaining elements. For example, for the set `{1, 2, 3}`, `{1, 3}` is a subset.
- **Subsequence**: A sequence derived from another sequence by deleting some elements without changing the order of the remaining elements. For example, in the sequence `[1, 2, 3]`, `[1, 3]` is a subsequence.
