# Ledger App

## Overview
The Ledger App is a financial management tool designed to help users track their income and expenses, manage budgets, and gain insights into their financial health. With a user-friendly interface and powerful features, the Ledger App makes it easy to stay on top of your finances and make informed decisions.

## Model
The Ledger App is built on a robust data model that includes the following key components:

- **User**: Represents the individual using the app, with associated financial data and preferences.
- **Transaction**: Represents a financial transaction, including details such as amount, date, category, and description.
- **Wallet**: Represents a user's financial account, which can include multiple transactions and balances.
- **Notification**: Represents alerts and reminders for upcoming bills, budget limits, or other financial events.
- **Bank Account**: Represents a user's bank account, including account number, balance, and transaction history.
